# 6_electronics: readout design and bill of materials

| File | What it is |
|---|---|
| `calc_readout.py` → `calc_readout_report.md`, `calc_readout.png` | Why a 100 kΩ reference: expected wet and dry readings, resolution, current (calculations, not measurements) |
| `kicad/` | KiCad 10 schematic of the two-zone reader (generated by `make_reader_schematic.py`; ERC 0 violations). Exports are in `kicad/out/` |
| `bom_v0_1.csv` | Bill of materials for the bench prototype: 23 lines, each linked to the file that needs it |

**About the BOM:**
- Every price is an **estimate** (about ₹2,400–11,000 in total). Check the supplier page before ordering.
- Fill in `have_it_YN` first; many items may already be in the lab.
- **Order first:** silver paint, a 1 % resistor set, 0.1 % 100 kΩ resistors, ADS1115, ESP32-C3 SuperMini, and a meter reading ≥ 20 MΩ if the lab has none.

The firmware is in `../7_firmware/`; the wiring table is `../7_firmware/WIRING.md`.
